# Compost Atlas — Fulton County

## What the images show

| File | Dimensions | Content |
|---|---|---|
| `hero.png` | 1600x900 | Fulton County outline (cream on warm gray) with 10 coral pins for permitted compost sites. Sites cluster in central Atlanta and along the south Fulton corridor. Italic Newsreader sub callout: *A discontinuous network across north and south Fulton.* |
| `card.png` | 800x600 | Same map at card scale with tighter title and no pin labels. |
| `thumb.png` | 240x150 | Same composition, no labels, no title, ten unlabeled coral dots on a cream Fulton outline. |

## Source

Generated with geopandas + matplotlib. Fulton County outline dissolved from `geojson/census_tracts_tiger.geojson` (327 tracts where COUNTYFP=121). Compost site points from `geojson/circular_economy.geojson`.

## Data date

**2026**. Ten compost and circular economy sites from the AFCN circular economy layer.
