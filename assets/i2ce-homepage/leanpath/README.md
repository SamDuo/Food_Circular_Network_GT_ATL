| File | Dimensions | Content |

## Source

Generated with matplotlib from the LeanPath waste audit data in `data/leanpath_surplus.js`. Editorial palette: coral `#e85a3c` bars on paper `#f4efe8`, IBM Plex Mono labels, Newsreader italic for the hero sub callout.

## Data date

**March 4 to 10, 2026**. Real LeanPath GT campus export. Total weight wasted 2,316 lbs across six locations and 408 entries.
